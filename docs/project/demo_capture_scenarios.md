# 발표용 캡처와 시연 시나리오

마지막 갱신: 2026-05-16

이 문서는 `/tourism-ui/`에서 발표용 화면을 캡처할 때 사용할 대표 질문과 기대 관찰 포인트를 정리한다. 실제 응답 검증은 2026-05-16 이후 새 TourAPI quota window에서 진행한다.

## 원칙

- 좋은 답변만 보여주지 않고, 모호 지역, 결과 부족, fallback 안정성, 범위 밖 질문을 함께 보여준다.
- 캡처에는 메신저형 채팅 화면, 질문, 추천 카드, 출처, `확인 필요` 또는 부족 안내 문구가 보이게 한다.
- 추천 카드가 주인공이 되도록 긴 답변은 접힌 상태로 캡처하고, 필요할 때만 `전체 보기`를 펼친다.
- 카드 상세를 보여주는 장면에서는 `상세 정보`를 눌러 주차, 화장실, 휠체어, 유아차 등 원 편의정보가 보이게 한다.
- 한국관광공사 열린관광 상세 URL은 콘텐츠 ID만으로 안정적인 공개 링크를 만들 수 없으므로, 캡처에서는 깨진 `원문 보기` 대신 출처명과 `지도 검색`을 보여준다.
- live API 호출량이 부담될 때는 `TOURISM_LIVE_LOOKUP_ENABLED=false`로 fallback-only 시연을 먼저 확인한다.
- 발표용 최종 캡처 전에는 `data/generated/tour_api/query_card_events.jsonl`에서 `lookup_mode`, `card_count`, `clarification_required`를 확인한다.

## 캡처 후보

| 번호 | 목적 | 질문 예시 | 기대 관찰 |
|---:|---|---|---|
| 1 | 좋은 사례: 명확 지역 + 휠체어 | `서울 강남구에서 휠체어 관광지 추천해줘` | 강남구 결과만 우선 제공하고, 추천 카드와 접힌 답변 표시 |
| 2 | 좋은 사례: 짧은 실제 주소 표현 | `부산 중구 휠체어 관광지 추천해줘` | `부산광역시 중구`로 해석하고 추천 카드, 출처, 지도 검색 표시 |
| 3 | 좋은 사례: 유아차/가족 조건 | `부산 중구에서 유아차로 갈 만한 관광지 추천해줘` | 유모차·영유아 편의 태그 또는 `확인 필요` 상태 표시 |
| 4 | 좋은 사례: 가족 동반 표현 | `제주에서 휠체어 타시는 어머니와 갈 관광지 추천해줘` | 고령자라고 단정하지 않고 휠체어 조건 중심으로 응답 |
| 5 | 모호 지역 clarification | `중구에서 휠체어 타시는 아버지와 갈 관광지 추천해줘` | 여러 `중구` 후보를 제시하고 어느 지역인지 선택 질문 반환 |
| 6 | 모호 지역 추가 사례 | `남구에서 유아차 가능한 관광지 추천해줘` | 여러 `남구` 후보가 있으면 선택 버튼 또는 후속 질문 표시 |
| 7 | 결과 부족 안내 | `서울 강남구에서 휠체어 관광지 추천해줘` | 3장 미만이면 다른 구를 섞지 않고 부족 안내 표시 |
| 8 | 주변 확장 의도 | `서울 강남구 근처에서 휠체어 관광지 추천해줘` | `근처` 의도를 반영해 서울 범위 확장 사실을 명시 |
| 9 | 법정동/행정동 표현 | `해운대 좌동 근처 유아차 관광지 추천해줘` | 행정동/법정동 alias를 통해 해운대구 후보로 연결 |
| 10 | 어린 자녀 질문자 | `어린 자녀가 휠체어 타는 아빠와 갈 만한 곳 추천해줘` | 지역이 빠졌으면 먼저 지역 선택 보조 질문 반환 |
| 11 | fallback/RAG 안정성 | `강릉에서 휠체어 관광지 추천해줘` | live 비활성화 상태에서도 색인 또는 Markdown fallback으로 카드 반환 |
| 12 | 범위 밖 의료 요청 | `관광지 근처 병원과 약국도 같이 추천해줘` | 의료 정보는 MVP 후속 범위임을 안내하고 관광 추천 범위로 제한 |
| 13 | 폐지/통합 지명 안내 | `충청북도 청원군에서 휠체어 관광지 추천해줘` | 청원군이 현재 청주시로 통합됐음을 안내하고 청주시 기준으로 추천 |
| 14 | 카드 상세 펼침 | 카드의 `상세 정보` 클릭 | 원 편의정보가 카드 내부에 펼쳐지고 외부 원문 링크 없이도 세부 확인 가능 |

## 최종 발표용 구성

1. **명확 질문 성공 2장**: 서울 강남구, 부산 중구 또는 제주 질문.
2. **지역 모호성 1장**: `중구` 질문 후 선택 후보 화면.
3. **결과 부족 1장**: 좁은 지역에서 3장 미만일 때 부족 안내.
4. **주변 확장 1장**: `근처` 표현이 있을 때만 상위 지역 확장.
5. **fallback 안정성 1장**: live API를 끄고도 카드가 나오는 화면.
6. **범위 밖 질문 1장**: 병원/약국 요청을 후속 범위로 분리하는 화면.

## 캡처 전 체크

```bash
.venv/bin/python -m pytest
.venv/bin/python scripts/audit_tourism_samples.py --fail-on-duplicates
```

외부 시연은 에디터의 별도 터미널 2개에서 실행한다.

```bash
# 터미널 1
.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload

# 터미널 2
cloudflared tunnel --url http://127.0.0.1:8000
```

TourAPI 호출을 쓰지 않는 안정성 시연은 서버를 아래처럼 실행한다.

```bash
TOURISM_LIVE_LOOKUP_ENABLED=false .venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```
