## 관광 정보 탐색·상담형 챗봇 정리

### 1. 서비스 개념

**관광 정보 탐색·상담형 챗봇**은 사용자가 관광 관련 질문을 자연어로 입력하면, 한국관광공사 OpenAPI와 RAG를 이용해 필요한 관광 정보를 찾아서 답변해주는 서비스입니다.

```
사용자 질문
→ 질문 의도 분석
→ 한국관광공사 OpenAPI 조회
→ RAG로 관련 정보 검색·정리
→ AI 챗봇 답변
→ 관광지 카드/출처 제공
```

이번 공모전은 **한국관광공사 OpenAPI와 생성형 AI 활용 개발도구를 필수 활용한 관광 서비스**를 요구하므로, 이 구조가 공모전 조건과 잘 맞습니다.

---

## 2. 여행 플래너와의 차이

| 구분 | 여행 플래너 | 관광 정보 탐색·상담 챗봇 |
| --- | --- | --- |
| 목적 | 여행 일정 생성 | 관광 정보 검색·상담 |
| 사용자 입력 | 날짜, 지역, 취향 | 자유로운 질문 |
| 결과 | 1일차/2일차 일정표 | 질문에 대한 관광 정보 답변 |
| 핵심 기능 | 코스 구성 | 정보 탐색, 조건 필터링, 근거 답변 |
| 예시 | “부산 2박 3일 일정 짜줘” | “부산에서 비 오는 날 갈 만한 곳 알려줘” |

즉, 이번 서비스는 **일정을 짜주는 앱이 아니라, 관광 정보를 물어보면 찾아서 상담해주는 챗봇**입니다.

## 3. 서비스 한 줄 정의

```
한국관광공사 OpenAPI와 RAG를 활용해 사용자의 자연어 질문에 맞는 관광 정보를 찾아 근거 기반으로 답변하는 AI 관광정보 상담 챗봇
```

## 4. 주요 사용자 질문 예시

```
“서울에서 아이랑 갈 만한 실내 관광지 알려줘.”

“부산에서 비 오는 날 갈 수 있는 곳 찾아줘.”

“강릉에서 반려견 동반 가능한 관광지가 있어?”

“휠체어 이용자가 방문하기 좋은 관광지는?”

“외국인 친구에게 소개할 만한 전통문화 체험 장소 알려줘.”

“대전 근처에서 역사 관련 관광지 추천해줘.”

“이번 주말에 열리는 지역 축제 알려줘.”
```

## 5. 핵심 기능

### 1) 자연어 질문 입력

사용자가 검색어가 아니라 문장으로 질문합니다.

```
“강릉에서 강아지랑 갈 수 있는 관광지 알려줘.”
```

---

### 2) 질문 의도 분석

AI가 질문에서 필요한 조건을 추출합니다.

```
{
  "지역":"강릉",
  "조건": ["반려견 동반"],
  "목적":"관광지 추천",
  "카테고리":"관광지"
}
```

---

### 3) 한국관광공사 OpenAPI 조회

질문 조건에 맞춰 관광공사 API를 호출합니다.

활용 가능한 데이터 예시는 다음과 같습니다.

```
- 지역 기반 관광지
- 위치 기반 관광지
- 행사/축제
- 음식점
- 숙박
- 관광지 상세정보
- 이미지 정보
```

---

### 4) RAG 검색

OpenAPI 결과와 저장된 관광 데이터를 바탕으로 관련 정보를 검색합니다.

```
질문 임베딩
→ 벡터DB 검색
→ 관련 관광 데이터 추출
→ LLM에 context로 전달
```

---

### 5) AI 답변 생성

챗봇이 사용자의 상황에 맞게 답변합니다.

```
강릉에서 반려견과 함께 방문하기 좋은 관광지는 아래와 같습니다.

1. ○○해변
- 추천 이유: 산책로가 넓고 야외 공간이 많음
- 위치: 강원도 강릉시 ○○
- 참고: 방문 전 반려동물 동반 가능 여부 확인 필요

2. ○○공원
...
```

---

### 6) 관광지 카드 제공

챗봇 답변 아래에 카드 형태로 정보를 보여줍니다.

```
관광지명
주소
이미지
간단 설명
전화번호
운영 정보
출처: 한국관광공사 OpenAPI
```

## 6. 추천 세부 주제

### A안. 무장애·가족 친화 관광정보 챗봇

```
장애인, 고령자, 유아 동반 가족이 방문하기 쉬운 관광지를 찾아주는 챗봇
```

장점:

```

문제의식 명확함
관광공사 공모전 취지와 잘 맞음
```

```
반려견과 함께 갈 수 있는 관광지, 숙소, 음식점 정보를 찾아주는 챗봇
```

장점:

```
수요가 명확함
차별화 쉬움
사용자 질문 예시가 직관적임
```

---

### C안. 외국인 관광객용 K-관광 Q&A 챗봇

```
외국인이 한국 관광 정보를 쉽게 찾을 수 있도록 안내하는 챗봇
```

장점:

```
확장성 높음
다국어 서비스로 발전 가능
관광 서비스 방향성과 잘 맞음
```

## 7. 가장 추천하는 방향

가장 안정적인 방향은 이겁니다.

```
무장애·가족 친화 관광정보 AI 챗봇
```

또는

```
반려동물 동반 관광정보 AI 챗봇
```

둘 중 하나를 고르는 게 좋습니다.

개인적으로는 공모전용으로는 **무장애·가족 친화 관광정보 챗봇**이 더 유리합니다.

이유:

```
1. 공공성이 강함
2. 문제 해결 의도가 명확함
3. 심사 기준의 기획력·확장성에 유리함
4. 단순 관광 검색보다 사회적 가치가 있음
```

## 8. 기술 구조

```
Flutter 앱
 ↓
FastAPI 서버
 ↓
질문 분석 모듈
 ↓
한국관광공사 OpenAPI
 ↓
RAG 검색
 ↓
Ollama / supergemma4-e4b-abliterated Q4_K_M
 ↓
답변 생성
 ↓
Flutter 앱 출력
```

추천 스택:

| 역할 | 기술 |
| --- | --- |
| 앱 | Flutter |
| 백엔드 | FastAPI |
| LLM | Ollama + supergemma4-e4b-abliterated Q4_K_M |
| 비교 기준선 | gemma3:4b-it-q4_K_M |
| RAG | ChromaDB |
| 임베딩 | bge-m3 |
| 일반 DB | SQLite |
| 서버 | Ryzen 7 5800H 미니 PC / VPS / NAS |
| 외부 접속 | Cloudflare Tunnel 또는 ngrok |
| 테스트 | Flutter 앱 / Jupyter Notebook Python 테스트 |

비교 실험:

| 구분 | 모델 |
| --- | --- |
| 1차 후보 | hf.co/mradermacher/supergemma4-e4b-abliterated-i1-GGUF:Q4_K_M |
| 기준선 | gemma3:4b-it-q4_K_M |
| 예비 기준선 | gemma4:4b-q4_K_M |

실험은 임베딩 모델을 bge-m3로 고정하고, 같은 ChromaDB 인덱스와 같은 질문 세트를 사용해 LLM 답변 생성 품질만 비교한다.

1. Ollama 모델과 bge-m3를 준비한다.
2. 관광 문서를 data/raw/에 넣고 `python scripts/rebuild_index.py`로 재색인한다.
3. `.env`의 `OLLAMA_CHAT_MODEL`을 1차 후보로 설정하고 서버를 재시작한다.
4. Jupyter Notebook에서 같은 질문 세트를 실행해 응답, 출처, 응답 시간을 기록한다.
5. `OLLAMA_CHAT_MODEL`을 기준선 모델로 바꾸고 서버를 재시작한다.
6. 동일 질문 세트를 다시 실행한다.
7. 한국어 자연스러움, 근거 준수, 모름 처리, 관광 상담 적합성, 출처 유지, 응답 속도를 1~5점으로 평가한다.

## 9. MVP 기능 범위

공모전용 최소 구현은 아래 정도면 됩니다.

```
1. 챗봇 질문 입력
2. 지역/조건/카테고리 추출
3. 한국관광공사 OpenAPI 호출
4. 관광 데이터 RAG 검색
5. 근거 기반 답변 생성
6. 관광지 카드 3~5개 표시
7. 출처 표시
```

우선순위는:

```
챗봇 답변 품질 > API 활용 명확성 > UI 완성도 > 부가 기능
```

## 11. 공모전 어필 포인트

심사 기준에 맞춰 이렇게 설명하면 좋습니다.

### 기획력

```
관광 정보는 많지만, 사용자가 상황에 맞는 정보를 직접 찾기 어렵다.
이 서비스는 사용자의 질문을 이해하고, 관광공사 데이터를 바탕으로 필요한 정보를 상담하듯 제공한다.
```

### 실현 가능성

```
한국관광공사 OpenAPI, RAG, LLM을 결합해 실제 동작 가능한 챗봇 형태로 구현한다.
```

### 확장성

```
무장애 관광, 반려동물 관광, 외국인 관광, 지역 축제 안내, 지자체 관광 챗봇으로 확장 가능하다.
```

### 데이터 활용 적절성

```
한국관광공사 OpenAPI의 관광지, 축제, 숙박, 음식점, 상세정보, 이미지 데이터를 핵심 기능에 직접 활용한다.
```
