현재 응답 방식

1. 질문 구조화 지역, 시군구, 휠체어/유아차/주차/화장실 조건, 근처 확장 의도를 먼저 분리합니다.
2. 캐시/Fallback 우선 이전 live 캐시와 Chroma/Markdown fallback을 먼저 보고, 없을 때만 TourAPI 후보를 조회합니다.
3. Live on miss 저장된 카드가 없으면 live 조회 결과를 카드화해 live Markdown 캐시에 남깁니다.

fallback 샘플은 전국 전체 장소 DB가 아니라, 광역권별 약 20장 수준의 최소 안전망입니다. 실제 방문 전에는 공식 안내와 현장 정보를 다시 확인해야 합니다.

사용법과 유의점

사용법

  • 지역 버튼으로 먼저 범위를 잡거나, 질문 입력창에 자유롭게 문장을 입력합니다.
  • `중구`처럼 여러 시도에 있는 지명은 추천 대신 “어느 지역인지” 추가 질문과 지역 선택 버튼을 보여줍니다.
  • `해운대 좌동`, `창원 마산합포구`처럼 법정동/행정동/일반구가 섞인 질문도 시군구 후보로 해석합니다.
  • 응답 상태에는 live 캐시, live API, 색인 검색, 샘플 fallback 중 어떤 경로를 썼는지 표시됩니다.
  • Swagger, ReDoc, OpenAPI JSON 링크로 현재 API 계약을 바로 확인할 수 있습니다.

테스트 범위

  • 기본 응답은 지역 확정 후 live 캐시와 fallback을 먼저 보고, 없으면 live TourAPI 후보 조회를 사용합니다.
  • fallback 샘플은 광역권별 약 20장 수준의 최소 안전망입니다.
  • 행정동/법정동 매칭은 행안부 주민등록주소코드 기반 가공 데이터를 사용합니다.
  • 휠체어, 유아차, 접근로, 화장실, 주차 같은 조건을 명시하면 카드 정렬에 반영됩니다.

유의점

  • OpenAPI에 없는 편의정보는 추측하지 않고 `확인 필요`로 남깁니다.
  • `아빠`, `어머니`, `부모님` 같은 관계 호칭만으로 나이를 추정하지 않습니다.
  • 실제 방문 전에는 공식 안내, 전화, 현장 정보를 다시 확인해야 합니다.
