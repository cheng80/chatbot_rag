사용법과 유의점

사용법

  • 지역 버튼으로 먼저 범위를 잡거나, 질문 입력창에 자유롭게 문장을 입력합니다.
  • `중구`처럼 여러 시도에 있는 지명은 추천 대신 “어느 지역인지” 추가 질문과 지역 선택 버튼을 보여줍니다.
  • `해운대 좌동`, `창원 마산합포구`처럼 법정동/행정동/일반구가 섞인 질문도 시군구 후보로 해석합니다.
  • 복합 조건 질문은 후보 카드 생성 뒤 추론 보조가 켜질 수 있으며, 개발 모드에서 사용 여부와 확인 필요 메모를 볼 수 있습니다.

개발 모드

  • 상단 `DBG` 버튼을 누르면 API 주소, Swagger, ReDoc, OpenAPI JSON, 응답 경로 상태를 확인할 수 있습니다.
  • 기본 URL은 개발 모드이며 `?mode=release` 또는 `?debug=0`을 붙이면 실제 사용자 화면만 보입니다.
  • live 캐시, live API, 색인 검색, 샘플 fallback 중 어떤 경로를 썼는지 디버그 패널에 표시됩니다.

유의점

  • 운영 시간과 편의시설 위치는 현장 상황에 따라 달라질 수 있어 방문 전 공식 안내나 전화로 한 번 더 확인하는 흐름을 유지합니다.
  • `아빠`, `어머니`, `부모님` 같은 관계 호칭만으로 나이를 추정하지 않습니다.
  • 실제 방문 전에는 공식 안내, 전화, 현장 정보를 다시 확인해야 합니다.
