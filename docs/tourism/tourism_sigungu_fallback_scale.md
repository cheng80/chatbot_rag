# 전국 시군구 fallback 최소 수집 규모

마지막 갱신: 2026-05-15

## 목적

현재 확보한 fallback은 광역권별 약 20장 수준의 최소 안전망이다.  
이 문서는 나중에 fallback을 **전국 시군구 단위**로 더 촘촘히 만들 경우, 어느 정도 데이터와 API 호출이 필요한지 미리 계산한 규모표다.

추가 API 호출 없이 `data/processed/tour_area_codes.json`의 `area_codes` 기준으로 계산했다. 실제 서비스 목표는 자치 시군구뿐 아니라 행정시, 일반구처럼 사용자가 지역명으로 묻는 단위까지 포함해 전국 실사용 지역 250개를 안전 기준으로 둔다.

## 결론

- 전국 실사용 지역 목표: **250개**
- 지역별 3장 fallback: **750장**
- 지역별 5장 fallback: **1,250장**
- 지역별 10장 fallback: **2,500장**
- 엔드포인트별 1,000건/일 제한을 고려하면, 전국 시군구별 5장 이상은 하루에 끝내지 않는 것이 안전하다.
- 평시 폴백용 수집 안전치는 엔드포인트별 1일 한도의 50%인 **500건 이하**로 둔다. 2026-05-15에는 사용자의 명시 승인으로 1,000건 기준까지 일시 확장했지만, 429가 나오면 즉시 중단한다.
- 현재 TourAPI 지역 코드 234개 기준 수집 옵션은 구현했고, 2026-05-16 이어받기 수집 후 234개 중 228개 시군구가 3장 이상 확보됐다. 0장 지역은 청원군, 마산시, 진해시, 남제주군, 북제주군이고, 3장 미만 지역은 계룡시 1장이다. 0장 5개 지역은 폐지/통합 지명으로 보고 사용자 질문에서는 청원군 -> 청주시, 마산시 -> 창원시, 진해시 -> 창원시 진해구 안내/TourAPI 창원시 기준, 남제주군 -> 서귀포시, 북제주군 -> 제주시로 안내한다. 전국 실사용 지역 250개 기준 대상 목록 확장은 아직 남아 있다.
- 행정동/법정동 매칭 데이터는 `docs/tourism/admin_region_aliases.md` 기준으로 생성했다. 현재 행안부 현행 코드 기준은 228개 시군구, TourAPI 캐시는 234개 시군구, 제품 목표는 250개 실사용 지역으로 서로 다르다.

## 호출량 계산식

시군구 하나를 수집할 때 대략 다음 호출이 필요하다.

```text
areaBasedList2 1회
detailCommon2 N회
detailWithTour2 N회
```

따라서 시군구별 `N`장 후보를 확인하면:

```text
총 호출 수 = 시군구 수 * (1 + 2N)
```

단, 일일 제한은 전체 합산이 아니라 엔드포인트별로 볼 가능성이 크므로 특히 `detailCommon2`, `detailWithTour2` 호출 수를 따로 봐야 한다.

## 권장 수집 전략

### 1단계: 지금 상태 유지

현재 이미 광역권별 약 20장 수준 fallback을 확보했다.  
당장 6월 10일 전 기본 서비스 완성에는 충분한 안전망이다.

### 2단계: 품질 QA 후 부족한 시군구만 보강

전국 250개 실사용 지역을 무조건 수집하지 않는다.

우선 확인할 것:

- live 결과가 자주 비는 시군구
- 동명이 지역 테스트에 자주 쓰는 `중구`, `남구`, `동구`, `서구`, `북구`
- 사용자 질문 가능성이 높은 서울/부산/인천/제주/강원 주요 시군구
- 음식점/숙박업소가 과하게 섞이는 지역

### 3단계: 정말 전국 시군구 fallback이 필요하면 3장부터

전국 250개 지역별 3장은 `detailCommon2`와 `detailWithTour2`가 각각 750회라 엔드포인트별 1,000건 안에는 들어온다.
하지만 이 프로젝트의 평시 폴백용 수집 안전치는 엔드포인트별 500건 이하로 둔다. 이미 당일 사용량이 있으면 남은 500건 안에서만 수집하고, 초과분은 다음 quota window로 넘긴다. 1,000건 기준 예외 수집은 사용자가 명시 승인한 날에만 수행한다.

권장 분할:

```text
Day A: 엔드포인트별 누적 500건까지 부족 시군구 수집
Day B: 남은 부족 시군구 수집
Day C: 실패/빈 지역 재시도
```

### 4단계: 시군구별 5장 이상은 며칠로 분리

250개 지역별 5장은 `detailCommon2`와 `detailWithTour2`가 각각 1,250회라 엔드포인트별 1,000건을 넘는다.

따라서 최소 2일, 안전하게는 3일 이상으로 나눠야 한다.

## 지금 당장 하지 말 것

- 429가 발생한 같은 날 추가 수집
- 전국 시군구 5장 이상 일괄 수집
- 외부 터널을 열어 둔 채 live UI 반복 테스트
- 부족 여부를 확인하지 않고 같은 지역 배치 재수집

## 다음에 구현할 수집 옵션

현재 수집 스크립트는 광역 단위 batch와 시군구 단위 fallback을 모두 지원한다. 시군구 단위 fallback은 다음 옵션을 사용한다.

```text
--sigungu-fallback
--cards-per-sigungu 3
--areas '서울,부산,인천'
--max-api-calls 300
--skip-existing
```

이 옵션은 이미 있는 지역 Markdown을 덮어쓰기보다, 없는 시군구만 채우는 방식이어야 한다.
